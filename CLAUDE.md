# LeepX website — rules for Claude

Read this before changing anything. Sambhav, Shreya and Riya are non-technical; explain in plain words.

## What this is
Static marketing site for LeepX (theleepx.com): home page, free assessment, five course pages, masterclass page, legal pages.
Published automatically by GitHub Pages from `main` (see `.github/workflows/deploy.yml`). No build step locally.

## How pages are made
- `site/index.html`, `site/assess.html`, `site/privacy.html`, `site/terms.html` are hand-edited.
- Course pages (`remote-launchpad`, `social-media-manager`, `virtual-assistant`, `ai-project-manager`, `masterclass`) are
  GENERATED by `tools/course-pages.py`. Edit the content in that script, then run `python3 tools/course-pages.py`.
  Never edit the generated HTML by hand; it is overwritten.
- Shared CSS: `site/css/leepx.css` (tokens, buttons, stickers, floating button) and `site/css/course.css` (course page sections).
- Config: `site/js/config.js` (checkout links, WhatsApp number, community URL, masterclass URL and end date, analytics IDs).
- Assessment logic: `site/js/leepx-logic.js`, documented in `docs/Assessment-Logic.md`. Log every change there with the date.

## Brand and design rules
- Colours: purple `#4D1288`, lime `#C6F04A`, ink near-black. Fonts: Plus Jakarta Sans + JetBrains Mono.
- Icons: Lucide only (via `LX.icon`). No emoji except faces in testimonials.
- No "AI slop": no coloured side strips on cards, no generic dark cards with number chips. Prefer tick lists, white or lilac boxes, torn-ticket bonuses.
- Course pages must not repeat what the home page already has: founders, Shreya's story, general FAQs.
- Course pages: slim top bar (back link, logo, enrol button), compact centred hero, sections alternate soft / lilac / dark / warm.
- Mobile first: check every change at 390px wide. Sticky bottom CTA exists on course pages and home.

## Content rules
- Result page of the assessment: never show DIY steps, never link a "gap" to a program, never reveal the 60% earnings rule.
- Home page cohort card order: Remote Launchpad, AI PM, SMM, VA, LinkedIn. Waitlist: freelancing only.
- "1,000+ mentees so far". Srishti's deals are "in talks", never "signed".
- Prices and checkout links live in `tools/course-pages.py` (constants at the top of each course block) and `site/js/config.js`. Change both.
- Floating "Upcoming Masterclass" button: `MASTERCLASS_URL` / `MASTERCLASS_UNTIL` in `config.js`. Hidden on the masterclass page itself.
- Logos for tools are in `site/assets/logos/` (official marks only).

## Workflow for any change
1. Make the edit. If it touches a course page, run `python3 tools/course-pages.py`.
2. Preview: `python3 -m http.server 4601 --directory site`, check desktop and 390px mobile.
3. Add a dated line to `docs/Assessment-Logic.md` changelog.
4. Commit with a plain-English message and push to `main`. GitHub publishes it in about a minute.
5. Tell the user what changed and the live URL to check.

## Do not
- Touch DNS records for `academy.theleepx.com` or switch nameservers.
- Deploy the single-file bundle (`site/build-single.py` output) as the live site. It is for offline previews only.
- Add analytics IDs, fake testimonials, or placeholder claims without asking.
